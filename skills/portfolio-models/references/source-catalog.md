## Research policy

- EN is authoritative on original mathematics; RU/ZH add local applications, alternative assumptions and recent extensions, **not** substitute sources for original claims.
- Preserve year distinction: journal acceptance, online posting, print edition are not always identical (e.g., Esfahani–Kuhn online 2017, issue 2018).
- Source labels distinguish full inspected text, official abstracts and institutional records; a citation alone is not evidence of code correctness.
- For implementation disputes, return to the precise theorem and constraints, not a blog or an unsourced paraphrase. For data and execution details, go to exchange documentation.

**Formula-level traceability:** [formula → original → test](formula-trace.md). This map marks derived special cases and implementation-specific choices rather than making every mathematical statement sound directly copied from the paper.
