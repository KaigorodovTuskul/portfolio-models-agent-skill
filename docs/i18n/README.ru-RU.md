# Portfolio Models — количественная оптимизация портфеля и управление рисками

[English](../../README.md) · [简体中文](README.zh-CN.md) · **Русский**

Portfolio Models — открытый Agent Skill для **портфельной оптимизации, распределения активов и риск-менеджмента**. Он объединяет точные математические постановки, работающие реализации на Python, проверяемые научные первоисточники и правила корректного исторического тестирования. Архитектура построена на **постепенном раскрытии контекста**: агент сначала читает короткий `SKILL.md` и обращается к формулам, коду или первоисточникам только по необходимости.

## Установка

```bash
npx skills add KaigorodovTuskul/portfolio-models-agent-skill --skill portfolio-models
```

Либо скопируйте `skills/portfolio-models/` в каталог навыков совместимого агента. Все рабочие инструкции, программный код и техническая документация проекта написаны **на английском языке**; этот файл — перевод README.

## Реализованные методы

В библиотеке есть Markowitz MVO, Global Minimum Variance, оценка ковариации Ledoit–Wolf / OAS, максимум коэффициента Шарпа, Black–Litterman, Equal Risk Contribution, Risk Budgeting, HRP, Maximum Diversification, Mean-Semivariance, CVaR / Mean-CVaR, CDaR / Mean-CDaR, Robust MVO с неопределённостью доходности и ковариаций, Wasserstein DRO-CVaR, Kelly, энтропический риск, минимизация ошибки отслеживания индекса и минимальная дисперсия со штрафом за оборот.

**Важно:** реализованная CDaR относится к **аддитивной траектории накопленной прибыли**, а не к просадке сложной стоимости портфеля. Реализация Wasserstein DRO охватывает строго определённый частный случай с указанной метрикой и носителем распределения. Значения целевых функций разных моделей напрямую несопоставимы.

## Запуск

Требуется Python 3.10+.

```bash
python -m pip install -r requirements.txt
python skills/portfolio-models/scripts/comparison_demo.py
python -m pytest -q tests
python scripts/stress_solvers.py
python scripts/goal_workflow.py check
```

Для своих данных используйте `portfolio_cli.py`: CSV должен содержать дату и столбцы **простых доходностей с учётом выплат**, выраженных десятичными числами и рассчитанных в одной валюте. Например:

```bash
python skills/portfolio-models/scripts/portfolio_cli.py datasets/synthetic_monthly_returns.csv --model robust-cov-mvo --rho 0.0005
```

Поставляемый набор содержит **синтетические**, а не рыночные доходности. Он нужен для воспроизводимых проверок формул и не является доказательством прибыльности модели. **В GitHub Actions тесты не запускаются** — предусмотрена локальная проверка.

## Научные источники и контроль качества

[Каталог источников](../../skills/portfolio-models/references/source-catalog.md) включает оригинальные публикации на английском, русском и китайском языках. Для исторических выводов требуются данные, известные на дату решения, сопоставимый вневыборочный период, реалистичные торговые расходы, контроль ликвидности, простые эталоны и сопоставимый фактический риск.

Предусмотрен [регламент независимой оценки](../../workflows/goal-workflow.md) по четырём направлениям. Статус успешной внешней экспертизы присваивается только при наличии реальных независимых рецензий; формальное выполнение тестов не заменяет экспертную проверку.
